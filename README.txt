# BHISHMA ID Card Website

A modern, responsive blue-theme static website for BHISHMA ID Card.

## Files
- index.html — website structure and content
- styles.css — responsive styling
- script.js — mobile navigation and demo contact-form interaction

## Customize before publishing
1. Replace the placeholder phone number, email, address, and website URL.
2. Add real PDF files and update the Downloads links.
3. Connect the contact form to your preferred email/CRM/backend.
4. Replace the sample ID card graphic with your official BHISHMA branding if available.
5. Upload the three files to any static hosting service.

No external JavaScript libraries are required.
